[Paleta de Cores Personalizada do AlertaTerra]
Justificativa de escolha:
- Azul-espaço (#0A1929): remete ao espaço sideral, transmite seriedade
  institucional e cria fundo escuro confortável para leitura prolongada.
- Ciano-alerta (#00D4FF): cor de destaque que evoca tecnologia e dados
  de satélite, mantendo alto contraste WCAG AA sobre o fundo escuro.
- Vermelho/Laranja/Amarelo/Verde: cores convencionais de semáforo de
  risco, padrão internacional para alertas de desastres (ex: sistema
  de cores da Defesa Civil e Met Office UK).
Referência de boas práticas em design de sistemas de alerta:
Link: https://www.metoffice.gov.uk/weather/guides/severe-weather-advice
Data de acesso: 2026


[Tipografia - Google Fonts]
Família para títulos: Space Grotesk

espacial.

SEÇÃO 6 - IMAGENS E MÍDIAS
--------------------------------------------------------------------------------


[Status atual do projeto - SEM IMAGENS EXTERNAS]
O projeto AlertaTerra na versão entregue NÃO utiliza nenhuma imagem
externa, foto ou arquivo de mídia importado. Toda a identidade visual
é construída com:

1. SVG inline desenhado manualmente (logo, ícones, mapa do Brasil)
2. Emojis Unicode (para ícones simbólicos)
3. Gradientes e cores CSS puras (sem texturas ou backgrounds raster)
4. Placeholders genéricos para fotos de integrantes (gradiente CSS +
   emoji "👤")

Pastas reservadas para mídia futura:
- assets/img/  (fotos reais dos integrantes - 5 placeholders a substituir)
- assets/icons/ (ícones SVG adicionais, se necessário)
